# מאגר תחיקת הבנייה

כלי חיפוש בחקיקת התכנון והבנייה בישראל: 26 חוקים ותקנות, 1,975 סעיפים ממוספרים.
מקלידים שאלה בעברית פשוטה ומקבלים תשובה, את הסעיף המדויק, וציטוט מוכן להעתקה.

**הכלי:** https://ylevy5-png.github.io/tchika/

נוסחי החקיקה מבוססים על המהדורות המוגהות של [ויקיטקסט](https://he.wikisource.org),
רישיון CC BY-SA. הנוסח החקיקתי עצמו נקי מזכויות יוצרים לפי סעיף 6 לחוק זכות יוצרים,
התשס"ח-2007.

אינו ייעוץ משפטי ואינו תחליף לבדיקת הנוסח המחייב ברשומות.
